# Mario Paolantonio — Industrial Software Portfolio

Live website: https://mariopao14.github.io/

An animated, responsive portfolio showcasing four systems delivered into production:
- Supplier onboarding and internal administrative workflows
- Hazardous substances inventory with Kardex-style movements
- Field sales incident reporting
- A complete Manufacturing Execution System (MES) for a wood-manufacturing plant

## Current release: V3.2

- Full-width industrial landscape hero; headline, controls and systems console are actual HTML/CSS
- Refined navigation on desktop and mobile
- Four detailed case studies with high-fidelity illustrative mockups
- Animated production motif and responsive components
- Static site: no framework build step required

## Important distinctions

The interface images use fictional data and are design reconstructions rather than screenshots of confidential applications. Any MES performance figures are self-reported. A sales ordering application with bidirectional SAP Business One integration is in development; it is not counted among the four production systems.

## Deploy

GitHub Pages publishes from `main` / `(root)`. Open `index.html` to preview the site. CSS and JS are embedded to keep hosting simple.
